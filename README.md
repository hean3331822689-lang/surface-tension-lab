# 液体表面张力系数测量实验数据处理

这是一个第一版静态网页原型，用于物理竞赛中的液体表面张力系数测量实验数据处理。

## 当前功能

- 直接输入 `Umax`、拉脱后稳定电压 `U断` 和最大位移 `xmax`
- 不再使用过程数据拟合曲线
- 通过 `Umax` 与 `U断` 的差值换算电压差张力
- 扣除拉起液膜的重力修正 `G = ρLdxmaxg`
- 使用 `γ = [K(Umax - U断) - ρLdxmaxg] / 2L` 计算表面张力系数
- 支持门型金属框和金属环两种几何模型
- 中间区域实时展示当前计算结果和计算展开
- 按 GUM 思路计算 A 类、B 类、合成和扩展不确定度
- 输出置信水平不低于 0.95 的置信区间
- 自动生成网页实验报告

## 使用方式

直接在浏览器中打开 `index.html` 即可使用。

第一版不依赖后端和构建工具，后续可以迁移到 React + TypeScript 项目结构。
