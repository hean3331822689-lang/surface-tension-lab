# 液体表面张力系数测量实验数据处理

这是一个单页静态网页原型，用于物理竞赛中的液体表面张力系数测量实验数据处理。页面入口包含测量不确定度基础知识考核，完成答题并查看解析后才能进入实验数据处理工具。

## 当前功能

- 前置 5 题单选考核，题目依据 GB/T 27418-2017《测量不确定度评定和表示》
- 提交后自动显示正确答案、答题反馈、解析和正确率
- 完成考核后进入实验数据处理工具，刷新页面会重新回到考核入口
- 输入多次测量数组 `U1`、`U2`、`h`
- 使用 `γ = (U1 - U2)/(2KL) - ρgdh/2` 计算表面张力系数
- 按 `uA = sqrt(sum((xi-xavg)^2)/(n(n-1)))` 计算 A 类不确定度
- 按 `uB = Δ仪/sqrt(3)` 计算 B 类不确定度
- 对 `U1`、`U2`、`h` 分别合成标准不确定度
- 通过偏导传播计算 `uγ`，再用 `kp=2` 得到扩展不确定度
- 默认示例数据采用当前实验 11 组测量值
- 自动生成网页实验报告
- `index.html` 为 CSS 与 JS 内嵌的单文件页面，不依赖本地存储、后端或构建工具

## 使用方式

直接在浏览器中打开 `index.html` 即可使用；永久网页部署时使用同一份单文件页面内容。
